# We Got Lists

A shared grocery-list app for your phone, with a bold 16-bit pixel-art look.

- Make as many lists as you want; star one to open it automatically.
- Add items, cross them off, delete them, or clear the list.
- Share a list with friends: everyone sees changes live, and can ❤️ items.

Built as an installable website (PWA) hosted on GitHub Pages, with Supabase for accounts and data.

See `docs/PLAN.md` for decisions and the build plan, and `docs/mockups/` for the look options.
